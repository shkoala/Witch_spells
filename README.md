# Word Potion · SHKOALA

Игра для тренировки английских слов, фраз и предложений по переводу.

## Запуск

Распакуйте архив целиком и откройте `index.html` в современном браузере. Установка и сборка не нужны. Все картинки и код включены; внешние шрифты, сервисы и ключи не используются.

Для GitHub Pages загрузите **содержимое архива** в корень нового репозитория. Файл `index.html` должен лежать на верхнем уровне рядом с `app.js`, `core.js`, `styles.css` и папкой `assets`. Включите GitHub Pages для нужной ветки и корневой папки. Папка `tests` нужна только для проверки кода.

## Подготовка урока

На стартовой странице можно:

- заполнить таблицу: английское слово / фраза / предложение слева, перевод справа;
- нажать **Paste a list** и вставить пары из таблицы или обычного текста;
- нажать **Import file** и загрузить CSV, TSV или TXT;
- скачать образец через **Get a sample**;
- включить **Mix the order**, чтобы перемешать задания.

Перевод может быть на любом языке. Список сохраняется в браузере на этом устройстве; его можно изменить в любой момент через **Word list**. Для переноса между устройствами используйте исходный файл CSV/TSV/TXT.

### Формат списка

По одной паре на строку. Для ручной вставки удобнее точка с запятой:

```text
cat ; кот
kite ; воздушный змей
a green frog ; зелёная лягушка
I can fly. ; Я умею летать.
don't stop ; не останавливайся
```

При копировании двух колонок из Excel или Google Sheets принимается табуляция. В CSV запятые внутри полей нужно заключать в кавычки:

```csv
English,Translation
"Hello, Sam!","Привет, Сэм!"
"Cat, dog-bone.","Кот, собачья косточка."
```

Допускается необязательная первая строка `English,Translation`. Поддерживаются UTF-8 (с BOM и без) и Unicode UTF-16 с BOM. Для Excel выбирайте CSV UTF-8 или текст Unicode. Файлы XLSX нужно предварительно сохранить как CSV/TSV.

Ограничения: до 150 заданий, до 64 символов в английском ответе и до 240 символов в переводе. Размер загружаемого файла — до 2 МБ. Пустые строки пропускаются. Незаполненные пары и неподдерживаемые символы выводят понятную ошибку до старта игры.

## Как играть

1. Прочитайте перевод на пергаменте.
2. Нажимайте на баночки с буквами. Каждый пузырёк появляется у поверхности зелья и поднимается на своё место над шкафом, обходя лицо ведьмы справа.
3. Кнопки **Space** и **−** под шкафом добавляют пробел и дефис `-`. В шкафу находятся только 26 букв, в трёх рядах 9 + 9 + 8. Пробел в ответе показывается символом `␣`, чтобы его было легко проверить.
4. **⇧ A** делает следующую букву заглавной и выключается. Внизу также есть апостроф, точка, запятая, вопросительный и восклицательный знаки.
5. Нажмите **Brew!** рядом со **Skip / Next spell** под шкафом для проверки. При ошибке неверные пузырьки станут розовыми. **Undo** убирает последний символ; **Clear** очищает текущую попытку.
6. После правильного ответа нажмите **Next spell**. Кнопка **Skip** пропускает незавершённое задание. Итог показывает число выполненных и пропущенных заданий.

Регистр и пунктуация проверяются. Типографские апострофы `’` приводятся к `'`, а длинные тире `—` и `–` к `-` при подготовке списка. Несколько пробелов подряд заменяются одним; пробелы в начале и конце удаляются.

### Клавиатура

- Английские буквы, пробел и поддерживаемые знаки вводят символы. При русской раскладке буквенные клавиши работают по их английскому расположению.
- **Shift** работает как обычно; экранная **⇧ A** действует на одну следующую букву.
- **Backspace** — удалить последний символ.
- **Escape** — очистить попытку.
- **Enter** — проверить ответ; после успеха перейти дальше. Работает и после кликов по кнопкам.
- Звук включается кнопкой **Sound off / Sound on** и изначально выключен.

На узком вертикальном экране баночки перестраиваются в семь колонок. Для урока на большом экране удобнее горизонтальное положение. Настройка уменьшения анимации в системе учитывается.

## Брендинг

На первой странице — логотип SHKOALA без видимой белой подложки и **More games**, ведущая на указанный автором VK Donut. На игровом экране логотип и ссылка отсутствуют. Игровые надписи на простом английском.

## Структура и проверка

`index.html` — экраны; `styles.css` — оформление; `core.js` — разбор списков и проверка данных; `app.js` — игра и анимации; `assets/` — готовые иллюстрации и баночки.

Для разработчика, если установлен Node.js:

```sh
node --test tests/core.test.cjs
```

Иллюстрации и логотип предоставлены автором SHKOALA для этого проекта. Сторонние библиотеки не требуются.
